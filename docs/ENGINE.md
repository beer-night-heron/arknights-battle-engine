# 主战斗引擎的组成

主入口是 `arksim.battle.Battle`。单局在默认 `1/30` 秒的逻辑步长内推进，`run()` 一直执行到生命归零、所有已排程敌人处理完毕，或默认 600 秒上限。`step()` 可供程序逐帧读取状态。改变回放采样密度不会改变逻辑步长。

## 模块职责

0.45.71 号角的分组索敌依次处理自身阻挡、炮击范围、自身格近战回退，起手后保留本次分支。一技能发射不立即结束技能，按缓存的动作时长结束技力阻塞，不等待弹体消失；死亡退款独立保留。复活后的生命上限以最终倍率计算，保留底层属性供后续增减。分支与属性公式有本地组件依据，精确结束帧、特殊中断和当前热更分派仍为候选。

0.45.70 拉拽按弹体编号登记独立来源，各自保存初始距离、终点、拉力、期限及可中断的干员；多条链分别施力，一条链中断或到期只移除自身。到点后只在唯一有效来源时清零共同速度；溯光星源结束自身链条，歌蕾蒂娅保留期限并暂停施力，之后被移出终点范围仍可恢复施力。来源阻挡范围使用距离平方与半径平方减 0.05 比较，不检查空阻挡位。无来源编号的旧调用保留显式回退诊断，实际物理步、特殊免疫／停链、完整返回和热更仍为候选。

0.45.69 天空盒一技能复用弹体中的缓存攻击力，在到达落点时独立筛选范围对象；主目标途中死亡后保留缓存终点，来源退场后已发弹体继续执行。范围碰撞忽略迷彩，覆盖地面与空中，各对象保留独立伤害判定与其他不可选限制。0.45.70 补核默认弹体初始化流程，在发射生成时缓存攻击力，命中时目标防御等条件仍参与计算；完整来源伤害通知、二维飞行与真实抛物线投影、碰撞／停止及热更分派仍为候选，普通攻击原路径保留。

0.45.68 溯光星源二技能的主弹到达动作先于主伤害，另行选择附近对象发出连锁弹体；连锁读取命中时攻击力，保留普通攻击类型与无近／远程分类的伤害属性。主攻击施加停顿，连锁只结算伤害和拉拽，不额外增加停顿或攻速层数。拉拽缓存主弹落点，记录可中止链条的来源；中止仅结束未来拉力，保留已有惯性，后续其他来源拉拽不会被旧来源误清。主攻击选最远两目标后排序、子弹首次更新、链条返回／取消／多链与当前热更分派仍为候选。

0.45.67 号角按起手时的阻挡情况选择近战／远程动作和弹体；各次动作保留自己的动画时钟。远程一技能的伤害与照明分别发射，伤害按弹体落点筛选地面对象，照明区域独立反隐，不修改原隐匿状态。多个照明区域和来源退场后的有限区域分别按期限生效；真实回调相位、碰撞投影、飞行失效通知和当前热更仍为候选。

0.45.66 公共治疗起手接入动作记录，保留既有治疗队列、冷却和命中判定。动作有明确骨骼名称时使用该名称采样；塞雷娅二技能的动画随攻速缩放，固定最短等待单独保留，并在动作中攻速变化后仍以原始截止时间约束命中。固定时长动作独立，异步通知的精确相位仍为候选。

0.45.64 治疗动作结束与攻击冷却分开：已核对组件的黍／塞雷娅／引星棘刺一技能缓存动作时长，待命中动作处理完才结束技能，下一次攻击仍等待原冷却。锚点按起手事件与飞行速度计时，队友延迟撤回使用公共离场清理并关闭本次退款；普通撤退不受影响。落地再次检查条件。0.45.65 改为结束旧实体后重新生成，恢复明确保留的生命比例／技能剩余时间及卡片记录，外部效果不复制；有限来源回复继续原期限。转移不增加普通重部署惩罚，也不重新算一次技能释放。精确出场、索敌、复杂死亡通知与当前热更仍为候选。

0.45.63 已对应组件的动作使用独立时长缩放上限，命中、动态挂点采样及多段动画事件共用缩放。攻击间隔变化在单位更新时保留冷却和已播放的动画进度；固定间隔子弹出手后不重排，固定时长与既有形态路径独立。精确属性通知相位、动作混合、固定点和当前热更分派仍为候选。

魂灵迷彩分别持有来源标记，普通临时／永久状态继续独立计时；撤销来源不删除其他来源，显式移除清理全部对应标记。酒神范围附件在主包取消／闪避时仍触发，主目标神经伤害保持原伤判门；精确附件通知相位仍候选。蕾缪安弹药容量在开启技能时读取，在途技能不补弹、不因来源退场削减当前弹药，下次开启使用当前有效加成。

同优先级单位先按创建顺序更新，作为当前采用的同帧规则；状态、弹体与特殊回调仍保留既有分阶段执行，不能把这一约定说成已验证全部原生同帧通知。

0.45.62 隐德来希偷生命与伊内丝／天空盒复用应用前入口，处于来源输出及目标伤判之后、扣血之前；计算入口不再修改目标生命上限。既有完全阻挡、取消及闪避分支跳过通知，成功零包与部分吸收仍通知，属性比例／上限及来源清理保持。完全吸收的原生取消标志、特殊目标和同帧属性更新仍为候选。

0.45.61 隐德来希保命后的物理减伤使用公共 `RESISTANCE` 同类取高规则。黍播种、炼金单元和凯尔希·思衡托有限回血纳入受益者的生命回复总速率，共用逐生命计时器；有限地块／目标效果由已退场来源保留至原期限，其他依赖来源在场的光环照常关闭。登记／到期与单位更新的精确相位仍为候选。

0.45.60 乌尔比安 Y 使用输出通知判断被任意友方阻挡的目标，读取模组增伤；来源保持既有自身击杀入口，其他深海猎人击杀经公共死亡通知增加同一成长层数，避免重复计自身。九层阻挡门槛独立于潜能层数上限，既有共享计时与退场清理复用，新组件登记和同帧相位仍候选。

0.45.59 减伤包参数与 `RESISTANCE` 规则共享取高判定，在数值护盾前结算；`SCALE` 普通乘算独立保留。塞雷娅 Y 按模板包含物理／法术／真实／元素伤害，播种与歌蕾蒂娅仍只减物法；生命流失绕过这类通知。黍 Y 接入 15% 自身减伤，0.45.63 新组件确认实际 IncludePure 模板；通知相位仍保留诊断。

0.45.58 黍 Y 模组隐藏辅助天赋按 `20_root` 选择，三项已有条件满足至少两项时只加一次模组额外攻击；二／三级取各自黑板参数。0.45.63 新组件确认三标记的 2–3 条件检查及随来源分离的全局光环，基础四岁与两项在场条件保持原入口；登记／同帧选择仍为候选。

0.45.57 早露 Y 模组的学生技能人数包含永久生效技能；编队缓存沿用同一判定，避免凛冬二技能转为永久效果后移除额外加攻。充能／可操作状态保持原生命周期。

0.45.56 修正地图方向：行坐标向上增加，朝下应减少行坐标。攻击范围旋转、前方三格区域及技能方向向量与页面一致；旧回放不改写。

0.45.55 独立生命流失不经过反伤和公共目标应用通知，不消耗伊内丝／天空盒的首次命中名额；干员伤害入口也不继承攻击暴击和自动输出倍率。显式包参数、扣血／死亡以及普通伤害流程保留，完整原生生命变化通知仍有候选边界。

0.45.54 溯光星源范围脆弱登记与查询分离，迷彩和空中对象可登记；每个目标独立 0.1 秒检查原光环是否仍在，失去资格在下一检移除，期间返回保留原成长。成长按黑板周期及上限更新，实际两档参数一次成长就封顶，没有额外增加层数。死亡／漏出、来源退场与缺资料诊断保留，完整目标 Buff／来源光环及同帧相位仍为候选。

0.45.53 独立生命流失跳过来源适配器中的战斗计算／命中天赋及通缉增伤，避免误偷生命上限、建侵蚀、回命中生命或积累 Fever。普通伤害、生命变化与死亡处理保持，未将所有生命变化通知等同受伤通知。

0.45.52 星熊抵挡天赋不对治疗、独立生命流失、已退场单位或无敌／睡眠提前取消的包抽签或取得模组加攻；明确无视无敌的普通伤害继续参与。沿用既有提前取消边界，尚未将原有抵挡入口移至完整原生受伤通知相位。

0.45.51 蕾缪安模组的命中标记随目标更新末尾通知回技力，区别于伤害落地立即回复或固定等待 0.1 秒；多次命中独立，目标更新前死亡／漏出与来源退场丢弃，技力阻塞在通知时判断。零伤或后续伤害取消／闪避／抵挡不额外取消命中标记，直接伤害包不伪装攻击能力附件。当前接入目标单位更新入口，完整目标 Buff 计时／顺序、弹体缓存、特殊提前取消及热更仍为候选。

0.45.50 银灰模组精英／领袖计算增伤不额外筛普通攻击类型，附加／持续包可参与；模组附加法伤独立读来源当前攻击力与技能倍率，不带入主包历史倍率。直接附伤已有精英倍率，标识该路径避免再次叠乘；来源失效、发射／缓存和同帧计算相位仍候选。

0.45.49 歌蕾蒂娅第一模组距离附伤拒绝单次采样路程严格大于 4 的段，更新位置基线而不截断或结转；正常段与等于 4 保留。默认直接公式入口与轻重量天赋计算通知分开；目前二维段长是原生累计路程的近似，固定点、传送计量与结束通知仍为候选。

0.45.48 号角第一模组的被阻挡倍率按伤害计算条件处理，不额外筛普通攻击类型，附加／持续伤害包也参与；实际溅射逐目标检查、其他干员阻挡满足。治疗和独立生命移除不参与，弹体缓存、特殊对象与同帧相位仍为候选。

0.45.47 阿斯卡纶第一模组范围减速限定有效存活地面目标并检查不可选状态，迷彩不额外排除；空中、隐匿、无敌、睡眠和不可选对象不误用光环，当前范围与来源退场限制保留。侵蚀自身减速独立，不因光环失效删效果；光环登记、反隐组合、特殊状态与同帧／热更仍为候选。

0.45.46 新约能天使模组高生命回复按独立每秒 GE 检查维护唯一增益，首次等待一秒；受伤／治疗后等下一检，退场清理、再部署重建。特性周期生命流失不可致死，沿既有生命移除路径保留一生命、不消耗护盾；流失与检查相对顺序暂按资源排列候选，固定点、完整 modifier 跳过与同帧／热更仍为边界。

0.45.45 能天使第二模组地面攻速光环与普攻筛选分开，范围有效存活地面敌人参与，隐藏或不可普攻状态不额外排除，空中不参与。多敌不叠加，退出／来源退场清理；实际成员登记、特殊运动和同帧相位仍为候选，没有给光环添加未见于组件的周期。

0.45.44 号角第二模组二／三级的复活前属性由独立 0.1 秒周期检查维护，复活先建立增益，下次检查结束原攻速／防御和检查器。查询不提前刷新，不叠加重复 core，退场清理、再部署重建；复活治疗和未阻挡攻速保留，首次挂载、固定点与同帧交接仍为候选。

0.45.43 逻各斯第二天赋建立／续期减抗效果不额外筛法术或攻击类型，持续伤害也可建立；后续固定增量仍只参与法术伤害。期限、不叠加、跨来源续期和未解锁限制保留，计算／缓存时点、特殊取消和同帧通知仍为候选。

0.45.42 逻各斯另一模组按伤害计算通知向精英／领袖回技力，先于输出／扣血，不额外筛普通攻击；零包、之后取消／抵挡保留通知，技力阻塞仍生效。公共可选计算通知不改变未提供时的行为，治疗与独立生命移除不通知；弹体计算／缓存时点、提前取消和同帧／热更仍为候选。

0.45.41 纯烬艾雅法拉第二模组对范围友方建立独立元素状态周期，进入时检查，之后每 0.5 秒更新；后部署建立新周期，离开／退场移除贡献，多个受损对象不重复叠加攻速。元素爆发恢复期参与，禁疗／不可选不额外排除。普通持续治疗与一技能元素回复保留，光环启动／运动状态、固定点和同帧通知仍为候选。

0.45.40 斩业星熊模组二／三级的额外低生命加攻每 0.1 秒检查一次，阈值相等生效；跨过阈值或接受治疗在下一检增减，查询属性不更新。第二天赋随生命变化的基础增幅仍实时计算，退场清理、再部署重建；首次挂载、固定点和同帧相位仍为候选。

0.45.39 丰川祥子模组按独立 0.2 秒周期读取空地范围敌人数，首次等待；迷彩及不可普攻状态参与，普攻筛选不变，进入／离开等下一检，退场清理。光环登记、固定点和同帧相位仍为候选；共享 Fever 与范围延伸继续暂缓。

0.45.38 圣聆初雪模组使用空地通用范围计数，迷彩不被普攻筛选误排除；不可选状态、范围、存活及增伤上限保留，普攻选敌不改变。光环登记／移除、特殊不可选组合与精确输出相位仍为候选。

0.45.37 隐德来希第二模组的范围人数检查按本地组件周期推进：首次等待 0.5 秒，此后每 0.5 秒更新一次攻速条件，查询属性不会推进检查；退场清理、再部署重建。缺资料时保留旧兼容路径并输出缺失诊断；挂载、固定点和同帧相位仍为候选。

0.45.36 酒神第一天赋的范围元素包在来源仍在场时读取当前攻击力，区别于主攻击保存的倍率；一技能主目标的元素增幅不扩大溅射倍率。主包与来源离场时的旧回退保留，缓存交接、范围筛选及通知相位仍为候选。

0.45.35 将隐德来希第二模组的范围计数与收割者普攻筛选分离，按有效存活敌人及范围重叠计数，空中和不可普攻状态不漏算；不改变普攻选择。周期检查与特殊对象有效性映射仍为候选。

0.45.34 能天使固定破甲从伤后正伤检查迁到输出通知；每包叠一次、封顶续期、整组到期重建，当前已捕获的破甲不追溯增加，下一包使用新层数。治疗及独立生命移除不作为输出伤害事件，属性缓存组合、提前取消及热更仍为候选。

0.45.33 将圣聆初雪受击寒冷和斩业星熊反击迁入既有可选受伤通知，分别保留来源异常过滤及 NORMAL 法术包；斩业星熊模组附伤用输出通知和能力所属者／伤害标识过滤，附伤先击杀则外层停止，避免重复死亡与击杀。默认资源支持事件分流，特殊取消、能力族映射及同帧顺序仍为候选。

0.45.32 增加可选受伤通知，乌尔比安第二天赋在扣血前以当前生命判断强弱回复，先执行普通自身治疗，再处理伤害与致命判定；零包和后续伤害规则不会撤销已发通知。未传通知的调用保持原行为；特殊提前取消、掩码及热更仍为候选，没有全局更改无敌／睡眠取消边界。

0.45.31 将塑心第二模组升级后的附加元素伤害登记接入爆发开始／结束通知，已有爆发目标在部署时登记；每敌独立周期，结束后清理，再次爆发重新登记。复用无角色来源的普通元素伤害入口计入总击杀，沿用模组等级及脆弱，通知的精确同帧位置仍为候选。

引擎不会把所有干员、敌人、伤害和技能都放进同一种简单顺序。普通实体按更新优先级与共享创建顺序推进；部分延迟效果、弹体、Buff 与特定攻击有自己的处理阶段。改变阶段顺序可能影响同帧可见的目标位置、伤害和技能状态，因此目录整理与查看工具不会改动这些规则。

本地 `operator_attack_timing.json` 可按角色及其 `skills` 配置 `attack_duration`、`attack_hit_time`。默认沿用现有按有效攻击间隔缩放的候选流程；技能指定 `timing_scale="FIXED"` 时，前摇取非负的 `attack_hit_time` 与 `min_hit_time` 的较大值，不随攻击间隔缩放。正前摇仍交给主引擎的固定帧待命中包，不另建伤害时间轴。缺少普通和技能动作数据时，部分动作仍立即结算；独立的投射物落地时间不能用前摇代替。

多段动作可配置与段数相同的 `attack_hit_times`，每段分别等待对应事件，沿用同一动作开始时的缩放；也可用 `additional_attack_interval` 表示第一段之后的固定发射间隔。后续帧存于同一个待命中动作中，打断时一并取消，最后一段才通知一次攻击完成／弹药消耗；远程每段独立创建弹体，不在一个弹体上一次性结算整个连射。未经配置的零间隔多段仍为同次事件的多个伤害包。回放的技能状态保存 `pendingHitFrames`，用于查看待执行段数；实际接续继续重建完整引擎状态。

名单内 31 名角色的 36 个所选技能已有动作配置，复用同一待命中流程；音符、消耗仆役和回费也可以作为无需敌方目标的动作等待事件。星熊三技能采用独立固定周期，按当次目标结算；持续技能可配置 `startup_duration`。来源、方向选择和动画缩放仍为候选，既有形态／治疗／锤击校准流程保留。

普通追踪攻击可在普通／技能时序配置中分别声明 `projectile_key`、`projectile_delay_after_reached` 和 `keep_projectile_after_departure`。数值速度仍从本地弹体数据读取；到达后延迟与飞行分开，不把伤害提前到出手事件。配置不自动覆盖特殊运动、链条、治疗弹体或投掷落点；这些继续由对应运行时处理。`select_target_timing` 和 `recover_sp_if_target_dead` 只描述已接入的出手重选／单次死亡退款路径，不能当作所有失效通知都已原生验证。

普通追踪弹体与已接入的炼金投掷共用干员出手点选择：在实际发射事件查询动态姿态，必要时朝向当次目标；炼金投掷记录固定出手点，再沿现有二维路径飞到落点。目标为自身格也不能跳过出手点到落点的距离。已有图形资料而缺少弹体绑定时报告 `OPERATOR_PROJECTILE_BINDING_MISSING`，缺少资料继续中心回退。公共技能的子发射器不自动继承携带者挂点；治疗、音符、拉拽及无人机需分别接入。骨骼资料解析、实际发射检查和原生逐帧验证是不同覆盖范围。

## 随机判定的定向分析

`Battle(..., random_trace=True)` 使用与默认模式相同的 PCG32 序列，并可通过 `battle.rng.export()` 导出判定记录。每项包含 `kind`、`parameters`、`context`、同语义判定次数 `occurrence`、实际结果、原抽样结果以及本次消耗的原始整数。伤害处理区分暴击与各条闪避规则，命中率判定在原调用位置记录。

需要隔离某个概率分支时，可把记录作为 `random_tape` 传入，仅修改对应项的 `result`。来源、目标、候选目标顺序、逻辑帧、机制标识及参数必须保持一致；有缺项、余项或不一致即拒绝，`Battle.run()` 自动核对完整消费。自行逐帧运行时，结束后调用 `battle.rng.assert_consumed()` 核对。复演会照常推进模拟随机轴，记录被指定的结果与自然抽样结果，并标记 `outcome_replay=true`；这种运行只能说明指定分支下的行为，不能证明自然触发率或通关概率。

新增机制应通过具名抽样接口提供稳定实体编号和语义信息：`random_uniform(lower, upper, mechanism=..., source=..., details=...)` 返回左闭右开的连续数值；`choose_random_target` 接受机制与来源说明。相等的连续上下界不消耗随机数，单个候选目标沿用原流程消耗一次抽样。未经这些判定入口的直接随机请求不具有语义记录。

相同种子只保证本引擎在相同抽样顺序下重现自身结果。指定结果复演与随机算法、概率规律的验证应分别处理。

也可以直接向 `Battle` 传入 `squad`（`OperatorPlan` 配装列表，时间和坐标不参与携带效果）。显式编队要求所有操作引用已携带干员，部署配装必须与编队一致。不传编队时，从每名干员的首条部署推断携带配置；不同部署配装仍保留，但出现歧义时输出诊断。队伍天赋范围与候选边界见 [编队效果](SQUAD.md)。

如需逐帧使用，创建 `Battle` 后自行调用 `step()` 并检查结束条件。不要在 `run()` 完成后再对同一实例调用 `run()` 期待新的一局；每次计算建立新实例。

`data.py` 的数据目录是进程级配置，切换数据目录需重新加载输入。批量入口的工作进程接收独立配置；不建议在同一进程的多个线程中交替设置不同数据目录。

维什戴尔普通／S1 在现有追踪弹体流程中分别处理到达与停止。S1 子载体分别发射并缓存出手点，停止等待与伤害／状态分开；途中失去有效目标后保留缓存终点，已到达地面载体保留落点。超时先处理资源中的结束到达通知，再处理运动强制到达与停止伤害，不重新等待到达延迟。残影关联来源天赋、刷新／消耗／离场清理，随机模板触发顺序和每载体限制在技能运行时处理，不依赖“命中过”的集合。

魂灵之影复用同一单位、动作、技力、伤害与弹体流程，独立记录生命及自动技能，不触发普通攻击。第二天赋出生与 S3 召唤分支检查当前范围／空部署格／数量上限；生成单位读取本地属性并关联持有者，不占部署人数，持有者离场统一清理。迷彩按登场附加及来源退出处理，已有临时迷彩不会因覆盖而变为永久。攻击弹体缓存其终点，停顿和宿主残影在命中时处理，随机返技力在动作结束时处理并可严格复演。回放保存 `summoner`、`camouflaged` 和 `soulWards`。出生／动作相位、筛选细节、三维投影、超时／失效、复杂状态叠加和原生随机调用仍为候选，S3 本体攻击不在该召唤分支内。

荒芜拉普兰德一技能的独立浮游与本体攻击分开更新：初始态从本体出手事件安排延迟，切换态按各单元目标和周期推进。两状态复用技能控制入口与属性生命周期，不另建战斗引擎；回放状态记录浮游数量和各自目标，查询快照不推进随机流。各独立能力保存目标与已完成成长，首次实际命中的能力确定交接主单元；其停止时将成长转回普通态。重锁同一目标继续成长，换目标重置，阶段提高上限后的命中先推进成长再结算。切换中断普通态子弹体，已有本体弹体沿用原路径。状态映射、动作混合、缓存组合与返回相位仍为候选；原生随机流对齐与完整三维投影暂缓，具体范围见技能支持表。

可选本地时序中的 `projectile_lifecycle` 只应用到逐键核对的普通、治疗和技能弹体，当前有 30 个键；特殊链条、盾牌、音符、浮游仍由各自流程处理。有限寿命从出生阶段计算，在运动前检查；来源失效停止与到期共用已核对的停止路径，目标失效保存最后有效终点，固定终点不随目标移动。未配置的弹体保留原有失效行为。具体标志、原生句柄销毁与来源离场清理不是同一概念；当前默认控制代码、热更实际选择及跨实体通知仍需核对。

逻各斯天赋的随机出生等待在创建时抽取，出手挂点先缓存；等待期间不运动、不伤害、不显示，出生后才计飞行寿命。该决定参与随机记录与严格复演；原生 deterministic／trivial 随机源选择和固定延迟队列相位仍为候选。回放查询不额外抽签。

投币与余弹倾泻共用结束连射排程，等待各自动画事件，分别按 0.07／0.05 秒发射；期间不发起普通攻击或新技能。每发缓存伤害并走真实弹体，打断取消尚未发射的段，已发射弹体按各自配置继续。投币保持开始时标记的地面敌人，余弹按当前候选重选；投币正常结束与打断均执行清技力。新约能天使炸弹另保存独立出生／停止阶段、实际半径及固定落点，来源退场时按来源管理规则清理。技能状态保存 `endVolley`，便于回放和续编；事件量化、选择器通知、缓存组合及复杂打断仍保留候选边界。

## 结果字段

| 字段 | 含义 |
| --- | --- |
| `win`、`reason` | 是否全清，以及 `all_clear` / `life_points_depleted` / `timeout` / `operation_failed` |
| `time` | 结束时的模拟秒数 |
| `life_points`、`max_life_points` | 剩余与初始生命 |
| `enemies_spawned`、`enemies_killed`、`enemies_leaked` | 出场、击杀、漏怪计数 |
| `operators_deployed` | 结束时仍在场的存活干员数，并非部署动作总数 |
| `operator_metrics` | 各次部署的属性、伤害与存活统计 |
| `operation_results` | 全部计划操作的状态、时间、失败原因和上下文 |
| `seed`、`random_draws` | 种子与实际随机抽取次数 |
| `behavior_warnings`、`unsupported_behavior_nodes` | 行为模板未覆盖情况 |
| `mechanic_warnings`、`unsupported_mechanics` | 已能识别的机制缺口 |
| `assumptions` | 本局采用的近似规则说明 |
| `spawn_timing`、`enemy_attack_timing` | 使用的时序模式 |

这是胜负与诊断摘要，不是完整的战斗调用轨迹。回放工具另外保存每帧状态与由状态差生成的事件。

可选本地 `operator_graphics.json` 提供干员默认外观的前后面动画挂点采样及各弹体的单点／随机／循环出手组。主引擎沿用现有动作速度取样，左右镜像只作用于列偏移，已发射弹体保留出手位置。读取或显示挂点不会消耗随机数；实际发射的随机组选择进入随机记录。缺少资料时继续使用中心出手，缺少已配置挂点则报告诊断。回放单位可显示当前挂点，弹体保留出手点与挂点标识；续编输入签名包含这份本地资料。真实转身、动画混合、投影和调用顺序尚未闭合。

角色形态适配器还保存明确的切换与总攻击事件。动画配置来自本地 `operator_forms.json`；缺少配置会诊断，静态参数不等于固定帧执行顺序已验证。当前结城理三技能优先覆盖满潜能配置，返回本体时单独保留 `ALL_OUT` 总攻击阶段：保持无敌及普攻／技能限制，允许回复技力，尾段结束保留已回复技力。切换不统一释放全部阻挡，进入零阻挡形态按配置阶段释放；返回时保留阻挡关系。一次实战轮询支持阶段划分，具体进入时间和致命伤后的附加延迟来自可选配置；动画事件、伤害快照和特殊对象交接仍属候选。
