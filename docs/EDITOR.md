# 图形化编写操作

在项目根目录启动本地编辑器：

```powershell
python tools/editor.py
```

然后打开 `http://127.0.0.1:8873/planner.html`。保持运行窗口打开；退出时按 Ctrl+C。工具只使用 Python 标准库，仅监听本机，不会把游戏数据或计划发到外部服务。其他数据目录或端口可用 `--data-dir "数据目录"`、`--port 8874`；输出根目录默认 `local/`，可用 `--output-dir "本地目录"` 更换。

回放页 `viewer/index.html` 仍可直接双击使用；编辑页需要服务读取本地角色、技能、模组和地图。

## 先准备关卡和队伍

1. 在“关卡与队伍”搜索并选择地图。列表只显示本地已经导入对应关卡文件的项目；同名关卡用 ID 区分。
2. 搜索干员。首次选择默认最高精英化、满级、200% 信赖、满潜能，携带第一技能并选最高已解锁技能等级／专精，以及第一个已解锁模组的最高等级；没有技能或模组时不携带。可在右侧自行调整，重新打开已有队员时保留原配装。
3. 点击“加入队伍”。点击已有队伍卡片可修改练度，再点“保存练度”。同一名干员在当前方案使用统一配装，之后的每次部署沿用它。
4. 点击“开始编排操作”。手动技能默认等待开技能操作；需要自动释放时在配装中明确开启。

选择项按表内解锁条件筛选，保存时复用引擎的完整配装校验。潜能显示为一潜至该角色上限，导出仍使用引擎的增量编号。右侧属性预览为基础配装属性，战斗中的技能、天赋与其他修正以实际模拟为准。携带列表不会限制账号是否拥有这些角色，也没有好友助战、重复同角色或运行中更换携带技能的功能。

## 再编排时间操作

- 选择携带干员、操作类型和时间。秒数与 30 Hz 逻辑帧联动；非整数帧时刻仍按引擎的最早执行时间处理，旁边的帧数是近似显示。
- 部署时，在地图上点高亮的可部署格，选择朝向，再点“加入操作”。行 0 在最下方，列 0 在最左侧。
- 撤退、开技能、主动结束和模式切换不需要坐标。技能操作只开放当前携带技能支持的类型。
- 点击右侧操作可修改；同一时刻用上下箭头调整先后顺序，其他时刻按时间排序。删除按钮只移除该条操作。
- 可选择条件不满足时等待、跳过或停止。等待会阻塞后续计划；费用、冷却、技力和在场状态由运行时检查。

地图只显示截至滑块时刻的计划部署；不会预测死亡、费用不足、再部署失败或等待造成的实际延期。同格冲突会标在格子的提示中，“检查计划”也不等于整局操作一定成功。已有技能特殊效果和候选时序的限制仍见 [机制支持与缺口](MECHANICS.md)。

## 保存、导入与运行

“保存方案”保存关卡、队伍练度、全部已加入的操作和模拟选项，并提供浏览器下载。即使浏览器没有弹出下载，也能从页面提示的本地路径读取：

```text
local/plans/editor/<保存编号>/project.json  完整编辑方案
local/plans/editor/<保存编号>/plan.json     引擎操作 JSON
```

每次保存使用新目录，不覆盖先前文件。“导出操作 JSON”生成相同的两份本地文件，并下载 `plan.json`。它的格式与现有命令行一致，但不包含关卡或模拟选项；单独使用时需另外指定这些参数。

“导入”支持完整 `project.json` 或原有的操作数组 JSON。旧操作数组不包含地图，需先选对应关卡；同一干员多次部署使用不同配装时会拒绝导入，避免丢失原配置。整个方案导入时会替换当前编辑内容，有未保存修改时页面会提示。尚未点“加入操作／保存修改”的操作表单不在保存内容中；未保存的练度修改会在保存方案或开始编排前校验并加入队伍。

“运行模拟”调用原有主战斗引擎，不另写一套页面结算。完成后点击“打开本次回放”，原回放页直接读取对应结果；之后仍可点击“退出当前文件”选择其他本地回放。

```text
local/最新模拟/                 最近一次成功生成的回放与结果
local/模拟历史/                 上一版结果
local/editor/runs/<运行编号>/   本次方案、操作、运行日志及固定回放副本
```

同一编辑器服务一次运行一局。运行后继续改方案时，已生成的回放仍对应运行时的快照，页面会说明内容已有修改。服务重启后，旧的快捷回放链接不再有效，但对应本地 `replay.json` 仍可手动读取。当前运行器最多推进 600 秒；超出此时间的操作会给出提示。
