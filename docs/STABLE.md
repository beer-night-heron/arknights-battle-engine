# 0.45.111 试用稳定版

此版本固定为一个可独立运行的试用版本，保留主战斗引擎、统一计划编辑／回放工作台和当前技能实现。后续维护可在其他目录继续，使用者自己的方案和回放保存在本版本目录的 `local/` 中。

“稳定版”表示固定版本并经过必要检查，不表示所有干员、关卡或逐帧机制已完整复刻。具体范围和候选行为见 [技能支持](OPERATOR_SKILLS.md) 与 [机制说明](MECHANICS.md)。游戏数据不随 GitHub 源码或版本附件发布，需要按 [数据准备](DATA.md) 在本地提供。

本版包含截至 0.45.111 的所选自动技能、天赋与模组修正，包括魂灵同距离选格上下方向、隐藏阵营加成和连续普攻期间自动 NEXT 技能漏触发的修正。已核的简单效果可通过可选组件目录自动关联并读取模板；复杂主动作、有限／周期／派生组件及准确原生通知相位仍未全部接入。

维什戴尔支持普通攻击、S1、两天赋、魂灵自动技能和当前模组；S2／S3 本体攻击仍未完成。技能触发修正不保证原方案无漏通关；具体支持范围与候选边界见技能支持表。升级请使用新目录，保留旧稳定版及其方案、回放和运行数据。

在此版本根目录启动：

```powershell
python tools/editor.py --port 8877
```

打开 `http://127.0.0.1:8877/`，选择“写操作”或“看回放”。8877 用来与其他目录中的维护版及旧稳定版服务区分；不要同时在同一端口运行两个服务。

直接运行计划也应在本版本根目录执行：

```powershell
python tools/simulate.py --stage "关卡ID" --plan "local/plans/my-plan.json"
```

一次运行一局。保存方案使用新目录；生成的新回放更新本版本的 `local/最新模拟/`，前一版保存到本版本的 `local/模拟历史/`。回放续编需要同版本、同运行数据及完整方案。

保持本版本源码和运行数据固定，可让后续结果便于复现。需要更换版本时使用另一个目录，保留当前方案、回放和原始配置。
