# 使用指南

## 一次模拟的流程

准备本地数据 → 编写计划 JSON → 运行模拟 → 在浏览器中读取回放。所有命令均在项目根目录执行；命令中的“关卡ID”和文件路径需要换成实际值。

```powershell
python tools/list_data.py --kind stages
python tools/list_data.py --kind operators --query "干员名称"
python tools/simulate.py --stage "关卡ID" --plan "local/plans/my-plan.json"
```

`list_data.py --kind stages` 只列出已有对应关卡文件的关卡；`--limit` 控制显示数量。查询干员会返回 ID、部署类型和技能 ID。模组 ID 需要查阅 `battle_equip_table.json`，不要填写名称代替 ID。

## 输出在哪里

默认输出位于 `local/最新模拟/`：

| 文件 | 内容 | 用法 |
| --- | --- | --- |
| `replay.json` | 地图、路线、逐帧状态、事件、结果和版本信息 | 在 HTML 查看页读取 |
| `result.json` | 单局结果、警告、假设与干员统计 | 查看摘要或程序分析 |
| `manifest.json` | 生成时间、关卡、计划文件名、种子、时序模式和结果摘要 | 确认是哪次生成 |

生成成功后，原来的最新目录会移入 `local/模拟历史/`，新结果再成为最新。目录名和生成时间使用 UTC；不按文件修改时间猜测最新版。计算或写入失败不会替换原来的最新版。若写入阶段中断，历史目录可能保留 `_生成中_...` 文件夹，它不代表成功结果。

可用 `--output-dir "本地输出目录"` 更换输出根目录；该目录下面仍生成“最新模拟”和“模拟历史”。自定义输出目录若位于项目内，应放在 `local/` 下，以便保持本地资料隔离。

## HTML 查看

直接双击 `viewer/index.html`，不需要启动服务。沿用原来的深色战术回放页面，样式和脚本都包含在这一个 HTML 文件中。JSON 文件可以单独存放。

- 在“打开回放数据”中选择 `replay.json`。读取在浏览器本地完成。
- 点击底部的播放按钮或按空格播放/暂停；方向键与箭头按钮前进、后退一个保存的采样帧。
- 拖动底部时间轴，或点击右侧事件跳到对应时间。
- 点击地图上的单位或待部署卡片，左侧显示其状态。干员展示当前攻击力、防御力、法术抗性、攻击间隔、生命和阻挡上限等具体属性。
- 底部保留“目标路径 P”“攻击范围 R”“实体编号 I”开关；目标路径显示选中敌人的后续路线，攻击范围显示选中干员的范围格。
- “出手挂点 M”默认关闭；开启后用青色十字标出已记录的敌方挂点，虚线连接单位中心，选中敌人可在左侧查看挂点坐标。此开关只控制显示，模拟时仍需开启 `--enemy-muzzle` 才会记录挂点。旧回放未记录时禁用此开关，不根据模型名称推测位置。
- 右侧事件流保留关键、伤害、移动和全部筛选，显示当前时间附近最多 150 条匹配事件；不展示特定技能的高台触发与回响事件。
- 图例单独放在地图上方，区分蓝门、红门、干员、普通敌人、精英敌人、领袖敌人和传送门；敌人分类来自回放的 `levelType`。旧文件缺少分类字段时显示为灰色，详情注明“类型未记录”。
- 地图下方是只读待部署区，展示计划中的干员、当前部署费用、费用不足或再部署冷却；部署后卡片移出，离场后重新显示。点击卡片仅查看属性，不改变计划。
- 左侧分别显示技能技力条和自然恢复技力槽。离散恢复模式的槽积累满后增加 1 SP，连续恢复模式显示已有小数进度；技能期间保留进度并注明暂停。没有自然恢复或旧文件未记录时不推测进度。
- 费用保留两位小数，小数部分来自自然恢复计时进度；引擎仍使用已结算的整数费用判断能否部署。
- 右侧整列用于事件流。结果与机制诊断保留在导出的 `result.json` 中；旧回放缺少新属性和待部署字段时提示未记录。
- “退出当前文件”重新打开读取界面，随后可以读取下一份模拟。

回放是已计算状态的展示，不会在页面内重新计算战斗。默认每个逻辑帧保存一次；若导出时指定较大的采样间隔，箭头只能跳到保存帧。显示位置和 HP 已做小数压缩，不能用页面坐标精度代替引擎内部精度。事件记录由相邻逻辑帧状态变化生成，不是完整的攻击起手或内部调用日志。

## 导出参数

```powershell
python tools/simulate.py --help
```

| 参数 | 默认 / 说明 |
| --- | --- |
| `--stage`、`--plan` | 必填；关卡 ID 和计划路径 |
| `--data-dir` | 项目内的 `local/data/`；可指定外部目录 |
| `--label` | 回放方案名称，默认“模拟” |
| `--seed` | 默认 0；相同输入与种子可重复运行 |
| `--sample-interval` | 默认 `1/30` 秒，至少为一个逻辑帧；只改变保存密度 |
| `--spawn-timing` | 默认 `fast`；还可选 `client`、`frame_core` |
| `--enemy-attack-timing` | 默认 `float`；`mortar_frames` 是特定炮兵的可选整数帧间隔模式 |
| `--enemy-muzzle` | 默认关闭；按本地配置使用敌方三维发射挂点、目标受击点、弹体距离维度和到达容差 |
| `--enemy-turning` | 默认关闭；按配置时长模拟敌人的左右转身过程 |
| `--strict-behaviors` | 未支持行为树节点直接报错；不会检查所有机制缺口 |
| `--output-dir` | 默认 `local/` |

出怪模式会影响战斗结果：`fast` 使用标称时间；`client` 使用逐帧调度模型；`frame_core` 使用静态动作队列。它们不是画面速度选项，适用限制见 [机制支持与缺口](MECHANICS.md)。比较不同运行时请保持模式、数据版本和计划一致。

## 可选敌方挂点与转身

两个开关可独立使用，也适用于摘要命令。关闭时沿用中心发射，并跳过挂点数据加载和转身计算；不会取消远程敌人的攻击。

```powershell
python tools/simulate.py --stage "关卡ID" --plan "local/plans/my-plan.json" --enemy-muzzle --enemy-turning
```

配置文件为数据目录下可选的 `enemy_graphics.json`，格式见 [数据清单](DATA.md)。只开启挂点时，左右朝向即时切换；同时开启转身时，按配置时长线性插值左右缩放，只有横向挂点偏移随该缩放变化。竖直方向不改变既有左右朝向。攻击起手请求朝向目标，可配置移动时朝向当前路线点；转身不会额外延迟起手、发射或移动。

开启后遇到缺失单位配置时，会登记 `ENEMY_GRAPHIC_PROFILE` 诊断并回退；配置没有挂点时登记 `ENEMY_MUZZLE_OFFSET`。模型像素或未经转换的 Unity 坐标不能直接填为地图偏移。弹体配置可选择目标 HIT、二维或三维距离和到达容差；缺少 HIT 时登记 `PROJECTILE_TARGET_HIT` 并回退中心，具体格式见[本地数据准备](DATA.md)。回放与 manifest 保存开关；逐帧敌人状态的 `facing` 为左右缩放，`muzzle` 为挂点地图坐标，包含 z；页面仍按现有地图视图展示，不代表完整相机投影。非攻击姿态使用固定挂点，尚未接入完整移动和待机动画。

## 单局和批量摘要

```powershell
python -m arksim.cli --stage "关卡ID" --plan "local/plans/my-plan.json" --output "local/results/single.json"
python -m arksim.cli --stage "关卡ID" --plan "local/plans/my-plan.json" --runs 100 --seed 1000 --workers 4 --output "local/results/batch.json"
```

摘要输出包含 `results`、`summary`、`execution`。批量种子从 `--seed` 开始依次递增；没有进行随机抽取的确定性运行会复用首个结果，实际执行次数会明确记录。随机运行分别计算；`--confidence` 控制 Wilson 胜率区间，默认 0.95。确定性场景重复运行不构成独立随机试验。

`--json-out` 直接向终端输出摘要 JSON；`--output` 以 UTF-8 写文件，避免依赖终端重定向编码。这两种摘要均不能导入回放页面。

## 常见问题

| 现象 | 检查方向 |
| --- | --- |
| 缺少 JSON 文件 | 对照 [数据清单](DATA.md)，确认 `--data-dir` 与关卡文件 |
| 找不到关卡 / 干员 / 技能 ID | ID 需来自当前本地数据；名称不能代替 ID |
| 页面拒绝读取 | 应读取 `replay.json`，不是计划、摘要或原始日志 |
| 干员没有在计划时刻部署 | 费用、席位或再部署时间可能尚未满足，动作会等待 |
| 部署一直等不到，后面的动作也没执行 | 计划按顺序执行，等待中的部署会阻塞后续动作 |
| 手动技能自己释放 | 当前手动技能兼容为自动释放；暂不支持指定技能释放时刻 |
| HP、时序或机制与预期不同 | 查看结果中的警告、`unsupported_*` 和 `assumptions`，再核对支持范围 |
