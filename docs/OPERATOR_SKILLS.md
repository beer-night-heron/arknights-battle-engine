# 指定干员技能支持

本页列出截至 0.45.97 已接入主战斗引擎的技能效果。已接入名单优先覆盖自动触发技能；一名干员有多个自动技能时分别接入，荒芜拉普兰德按指定范围改为一技能。后续补充重点为自动技能与持续时间无限的手动技能，已接入的其他技能保留。自动回复技力和自动触发是不同概念，手动技能仍等待操作；部署配置 `auto_skill=true` 才开启满技力自动尝试。

名单共 31 名干员、36 个技能。其中结城理三技能、黍一技能和怒潮凛冬二技能沿用既有实现，其余技能复用主引擎的伤害包、治疗、技力、索敌、动作和弹体流程。参数按实际精英阶段、潜能、技能等级及已读取的模组黑板选择，不固定为满配数值。

“已接入”表示具备实际效果计算，**不表示全角色天赋、条件模组或原生逐帧时序已经完全验证**。名单内已逐人读取普通／技能组件、默认外观动作及配装黑板，补入 36 个所选技能的动作配置；已有形态、治疗与锤击流程保留。新接入技能仍输出 `OPERATOR_SKILL_TIMING_CANDIDATE` 诊断，动画缩放、正背面选择、皮肤差异和事件交接尚未完全闭合。名单外缺少时序配置的动作仍可能回退到普通前摇或起手当帧；不会统一平移伤害帧。

持续技能可先等待开技能动作再应用效果；下一击可等待独立动画事件，多段攻击逐段出手。已核对的普通追踪弹体分别选择普通／技能弹体键、到达后的延迟及来源离场行为；拉拽、链条、投掷、音符、无人机和起落等特殊运动仍使用各自流程与候选边界。一次技能的死亡退款不会因多段重复发生，已经出手后的失效规则仍需分别验证。

0.45.63 补 49 个可明确对应组件的普通／所选技能动作的时长缩放上限：负值不设上限，正值限制动画放慢倍数，而非限制播放速度。命中与动画使用同一缩放，多段动画事件逐段应用；固定时长动作不随攻速缩放。已核对动作的攻击间隔变化保留冷却进度及已播放的动画时间，固定间隔子弹只随首段出手整体平移，出手后的间隔不改。缺少组件元数据仍沿用旧候选，既有形态校准路径保持独立；属性回调相位、固定点、动作混合和热更尚未闭合。

**资料覆盖与实际发射覆盖不同。** 31 名默认外观骨骼资料已读取，但不代表所有技能、天赋和特殊对象都具有完整运动实现。0.45.5 补公共技能主绑定和炼金投掷；0.45.6 补两名治疗干员、歌蕾蒂娅、天空盒、音符与复合无人机的实际出手路径，以及盾牌绑定和绕行参数。缺少当前弹体绑定报告 `OPERATOR_PROJECTILE_BINDING_MISSING`，绑定存在但缺少挂点几何报告 `OPERATOR_MOUNT_MISSING`，保留中心回退。斩业星熊默认外观的 muzzle 引用为空，不能宣称盾牌具有已验证的动态出手点；复杂三维运动仍为候选。

## 全部模组的当前规则

隐德来希偷生命在伤害应用前通知触发，输出与计算阶段仍看到原生命上限；取消、闪避和既有完全阻挡不提前偷取，成功零包与部分护盾吸收仍参与。每敌削减上限和自身累计上限分开，扣血前维持生命比例，来源退场归还已施加的削减。特殊敌人状态映射、完全吸收的取消标志、属性组合和同帧通知仍为候选。

其持续法伤由独立输出通知建立，处于主伤害后续闪避／抵挡之前；非持续伤害输出可建立或续期，持续伤害自身不递归，来源退场保留原期限。无敌／睡眠等既有提前取消、生命流失、治疗和来源失效分支不建立；命中回复沿用原伤害应用条件。特殊提前取消和完整目标 Buff 相位仍为候选。

溯光星源第一天赋的范围脆弱与普攻迷彩筛选分开，迷彩和空中对象可以登记。每名敌人独立每 0.1 秒检查原光环资格，离开后保留至下一检，期间返回保留成长；实际黑板两档参数都只成长一次便达到上限，移除后再进入从初值开始。查询不创建或更新效果，死亡／漏出及来源退场清理；缺资料保留旧路径并诊断，完整目标 Buff／光环同帧顺序及热更仍为候选。

独立生命流失不调用来源适配器中的战斗计算及命中天赋，也不获得通缉增伤或触发反伤；隐德来希偷生命上限／侵蚀／命中回复、丰川祥子 Fever 和普通输出增伤保持在普通伤害路径。伊内丝／天空盒首次命中名额不被生命流失消耗，干员入口不为它继承攻击暴击和自动输出倍率。显式包参数、生命变化与死亡处理保留，特殊生命变化通知和完整原生相位仍有边界。

星熊的抵挡天赋及模组加攻排除治疗、独立生命流失、已退场单位以及无敌／睡眠提前取消的伤害；明确无视无敌的普通伤害仍参与。原有概率、五秒加攻和不叠加规则保持，完整原生受伤／抵挡通知及热更相位仍为候选。

蕾缪安模组的回技力由攻击弹体命中后的独立标记通知，随目标单位更新处理，不是立即回技力或等待标记的 0.1 秒寿命。多个目标和多次命中分别通知，目标更新前死亡／漏出或来源退场丢弃；技力阻塞在通知时判断，失败不补发。零伤或伤害包取消／闪避／抵挡不额外取消标记；直接伤害包不冒充攻击能力附件。完整目标 Buff 顺序、弹体缓存、特殊提前取消及热更仍为候选。

逻各斯第二天赋在伤害计算入口建立或续期减抗效果，不额外排除非法术或持续伤害类型；效果中的固定增量仍只加到法术伤害。已有不叠加、期限、跨来源续期及未解锁限制保持，计算／缓存时点、特殊取消和同帧通知仍为候选。

逻各斯另一模组对精英／领袖的回技力在伤害计算通知中处理，先于输出和扣血，不额外排除附加或持续伤害类型；零包或随后取消／抵挡也可通知，技力阻塞限制保留。治疗与独立生命移除不触发；弹体计算／缓存时点、既有提前取消及同帧／热更相位仍为候选。

纯烬艾雅法拉第二模组在范围友方进入时检查元素状态，此后每名友方独立每 0.5 秒检查；后部署成员有新周期，离开／退场移除贡献。元素爆发恢复期或任一元素未满均参与，禁疗和不可选状态不额外排除，多名受损友方只提供一次攻速。普通持续治疗与一技能元素回复保留；光环启动、运动状态／特殊对象、固定点和同帧通知仍为候选。

斩业星熊模组二／三级的额外低生命加攻按独立 0.1 秒周期判断，阈值相等生效；扣血和治疗后的增减在下一检发生，退场清理、再部署重建。基础天赋的生命比例增幅仍实时计算；缺时序资料的旧兼容路径会明确诊断，首次挂载、固定点和同帧相位仍为候选。

丰川祥子模组攻速首次等待 0.2 秒，随后每 0.2 秒读取范围计数；空地、迷彩及不可普攻状态参与，达到两名敌人增加一次攻速，退出范围在下一检移除。缺时序资料保留旧路径并诊断。光环计数登记、固定点和同帧相位仍为候选；共享 Fever 与范围延伸继续暂缓。

圣聆初雪模组的范围增伤计数空地通用，迷彩敌人也增加层数，但仍不能被普攻选中。不可选状态、当前范围、死亡／离开和增伤上限分别处理；治疗不获得此输出伤害增益。光环登记／移除、特殊不可选组合和精确输出相位仍为候选。

酒神第一天赋的溅射神经损伤在来源仍在场时使用当前攻击力，主攻击保存的倍率与一技能主目标元素增幅不误带入溅射。原主包、各模组元素修正、空地范围、免疫与恢复期保留；来源离场后的缓存回退、完整筛选及元素通知相位仍为候选。

隐德来希第二模组的攻速门槛独立统计范围内有效存活敌人，包含空中及不可普攻的隐匿／迷彩／无敌／睡眠状态；不扩大收割者普攻范围或可攻击对象。首次等待 0.5 秒，此后每 0.5 秒检查，进入／离开和范围变化在下次检查更新，退场清理、再部署重建。缺少本地周期资料时保留旧兼容路径并输出缺失诊断。能天使同类攻速条件仍要求地面敌人，两个条件分别处理；挂载、固定点／同帧检查相位及特殊对象有效性映射仍为候选。

能天使第二模组升级后的固定破甲按输出伤害包叠层：零包或之后被取消／闪避／抵挡也增加一层，满层续期，到期整组清掉再从一层重建；治疗、独立生命移除及已离场来源不叠。当前包已取得的破甲量不追溯重算，下一包取得新值；缓存与属性组合、特殊提前取消及热更仍为候选。

圣聆初雪受击寒冷检查攻击者的不可选／无敌／隐匿状态，迷彩允许；斩业星熊一技能及模组反击在扣血前发出 NORMAL 法术包，使用当时攻击力。其模组攻击附伤在输出时通知，只有当前所属攻击能力的普通包触发，模组标识包和反击不递归；附伤先杀目标时外层停止，不重复计杀。零包及后续伤判保留通知，特殊取消、能力族映射和同帧通知顺序仍为候选。

乌尔比安第二天赋在受伤通知中、实际扣血前判断当前生命并尝试自身治疗；满血先溢出，不会在扣血后再回复。零包及后续伤害规则取消／抵挡不撤销已有通知，生命阈值相等使用较强回复。普通治疗的禁疗、技能倍率和模组接受治疗倍率保留；既有无敌／睡眠提前取消、特殊掩码与热更通知仍有边界。

塑心第二模组二／三级的全场附加元素伤害按爆发开始登记即时首包、每敌独立每秒周期；爆发结束移除，部署时已有凋亡爆发也登记。无角色来源伤害计入总击杀，范围内元素脆弱继续参与，不计作塑心个人击杀。资源事件与触发参数明确，同帧通知位置及热更仍为候选。

## 召唤物操作与回放

编辑器根据携带者的所选技能，把已接入的诱导装置和战术锚点加入操作对象。无需把召唤物重复加入编队。导出时继承携带者的精英阶段和等级，运行时检查携带者、技能状态、地块、费用和冷却；不满足时沿用操作的 `WAIT`、`SKIP` 或 `STOP`。战术锚点只允许在携带者当前范围外的远程位部署，免费重新部署仍检查部署席位。风雪之眼在本次范围的 S1 中不能手动部署，仅用于待部署区位置关系。

自动生成的仆役与冻结蓝门会加入回放单位详情，不进入待部署区。冻结蓝门不占部署席位、不能治疗或手动撤退；携带者离场时移除。回放补充积雪、音符与无人机、金币、Fever 和锚点状态，仍使用原查看页面。

## 使用结果的边界

干员追踪弹体在提供本地挂点资料时，按默认外观的动态骨骼采样、模型层级、前后面和左右镜像发射；多段分别取当时位置。逻各斯第一天赋与三技能普通攻击使用两组不同的六挂点，前者已经接入独立弹体，后者的资料和共用挂点选择已可用，但三技能战斗效果不在本次范围。随机选择可记录及复演，原生随机调用顺序仍未确认；动作混合、转身过渡、皮肤与投影仍是候选。缺少对应资料时保留中心出手，特殊运动仍按各自边界说明。

定向检查覆盖技能选择、无目标保留充能、多段盾判定、持续属性还原、治疗与回技力、弹药、积雪蓝门、音符、盾牌锁定、无人机、召唤升级、炼金离场、编辑方案往返及召唤物编队校验。它们证明这些输入下的引擎行为，不证明所有技能等级、全关卡或原生逐帧一致。

复杂机制参考对应的 [PRTS 干员资料](https://prts.wiki/w/干员一览)，并与使用者的本地参数核对。与机制描述一致的静态规则和需要实战确认的时间／顺序分开记录。结果中的候选、天赋和模组诊断仍应保留；不能把固定种子可重跑或指定结果复演当作原生概率复刻证据。

0.45.14 将交接主单元改为首次实际命中的能力，不固定为第一个数组位置；各能力分别保存已完成成长，重锁同一目标或再次进入技能状态时延续，换目标重置。阶段提高上限后先更新成长再结算该次伤害。普通态子能力虽配置为不随分离自动中断，父能力分离流程仍主动中断正在出手的子能力，结束回调清理它们的弹体；因此切换取消尚未命中的普通浮游伤害，已有本体弹体按原流程处理。以上为当前资源与保存默认控制代码支持的实现，动作混合、主动作交接、周期精度和同帧通知仍为候选；原生随机流对齐及完整三维投影按当前约定暂缓。
